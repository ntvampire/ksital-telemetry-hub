\# КСИТАЛ Telemetry Hub — ТЗ и статус проекта



\## 1. Общее описание

Программный комплекс для круглосуточного (24/7) мониторинга и диспетчеризации контроллеров КСИТАЛ GSM, RADS CCU-825 и ОВЕН ПЛК.

Система разработана для автономной работы и устойчива к внезапным отключениям электроэнергии (автоматическое восстановление, предотвращение коррупции файлов базы данных).



\## 2. Архитектура проекта

\* \*\*Core\*\*: Доменные модели (TelemetryTarget, AlarmEvent), структуры данных и генератор SMS-команд.

\* \*\*Modem.Engine\*\*: Модуль связи с GSM-модемом по COM-порту (AT-команды, декодирование PDU).

\* \*\*Parser\*\*: Специфичные модули разбора сообщений для каждого типа поддерживаемых контроллеров.

\* \*\*Storage.Sqlite\*\*: База данных SQLite. Включен режим \*\*WAL\*\* и `DefaultTimeout=5` для защиты данных и предотвращения блокировок при конкурентном доступе между UI и фоновой службой.

\* \*\*Service.Worker\*\*: Системная служба Windows (Windows Service) для фонового сбора данных 24/7 без необходимости активного сеанса пользователя.

\* \*\*UI.Desktop\*\*: WPF-приложение диспетчера. Графики (OxyPlot), модальные окна тревог поверх всех окон, управление устройствами, настройка COM-портов.



\## 3. Развертывание и обновления

\* \*\*Сборка\*\*: Self-contained пакет под win-x64. Установщик генерируется через \*\*Inno Setup\*\* (с сохранением `telemetry.db` при накате обновлений, автоматической регистрацией службы и созданием ярлыков).

\* \*\*CI/CD\*\*: Настроен GitHub Actions (`release.yml`). Сборка запускается автоматически при пуше тега версии. Готовый `Setup.exe` публикуется в релизах GitHub.

\* \*\*Автоматизация\*\*: Локальные скрипты `release\_patch.bat` и `release\_minor.bat` (вызывают `bump\_release.ps1`), которые запрашивают Release Notes, автоматически повышают версию проекта в `.csproj` и пушат тег на сервер.

\* \*\*In-app Update\*\*: Встроенная в окно настроек проверка обновлений скачивает актуальный инсталлятор `.exe` или архив `.zip` из релизов GitHub и запускает процесс самообновления.
