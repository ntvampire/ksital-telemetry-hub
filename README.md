# КСИТАЛ Telemetry Hub

Централизованный диспетчерский пункт телеметрии и мониторинга для контроллеров **КСИТАЛ GSM**, **RADS CCU-825** и **ОВЕН ПЛК**.

Система рассчитана на автономную круглосуточную работу (24/7) и устойчива к аварийным отключениям электропитания.

## Установка на целевом ПК

Приложение скомпилировано в автономном режиме (**Self-Contained**) и не требует предварительной установки .NET SDK или сторонних библиотек.

### 1. Скачивание и распаковка
* Перейдите в раздел [Releases](https://github.com/ntvampire/ksital-telemetry-hub/releases) и скачайте архив последней версии (`ksital-hub-vх.х.х.zip`).
* Распакуйте содержимое архива в постоянный рабочий каталог на диске (рекомендуется `C:\KsitalHub`).

### 2. Первоначальная настройка службы
* Откройте распакованную папку.
* Кликните правой кнопкой мыши по файлу **`install.bat`** и выберите **«Запуск от имени администратора»**.
* Скрипт автоматически:
  * Зарегистрирует и запустит службу Windows `KsitalTelemetryWorker` со статусом автозапуска (24/7).
  * Настроит автоматический перезапуск службы при сбоях.
  * Создаст ярлык **«КСИТАЛ Telemetry Hub»** на Рабочем столе.

### 3. Первый запуск рабочего места
* Запустите приложение с помощью ярлыка на Рабочем столе (или через `start_ui.bat` / `UI.Desktop.exe`).
* При первом старте система автоматически инициализирует базу данных SQLite в отказоустойчивом режиме **WAL**.
* Перейдите в раздел **«⚙ Система»**, выберите COM-порт подключенного GSM-модема и нажмите **«Сохранить»**.

## Обновление программы

В диспетчерский интерфейс встроен механизм обновления:
1. В главном окне откройте **«⚙ Система»** и нажмите **«🔍 Проверить обновления»**.
2. При наличии новой версии программа предложит скачать пакет.
3. Система автоматически создаст резервную копию базы данных (`telemetry.db.bak`), обновит исполняемые файлы без затирания рабочей базы и перезапустится.

## Архитектура решения

* **Core** — общие структуры данных, отчеты телеметрии и конструктор команд.
* **Modem.Engine** — взаимодействие с GSM-модемом по AT-командам и декодирование PDU.
* **Parser.*** — модули разбора сообщений КСИТАЛ, RADS CCU-825 и ОВЕН ПЛК.
* **Storage.Sqlite** — хранилище объектов, телеметрии, тревог и очереди команд (WAL-режим, таймаут 5 сек).
* **Service.Worker** — системная служба Windows для круглосуточного приема SMS и отправки команд.
* **UI.Desktop** — интерфейс диспетчера (WPF) с карточками объектов, графиками, всплывающими окнами аварий и журналом.
