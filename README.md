# \# КСИТАЛ Telemetry Hub

# 

# Централизованный диспетчерский пункт телеметрии и мониторинга для контроллеров \*\*КСИТАЛ GSM\*\*, \*\*RADS CCU-825\*\* и \*\*ОВЕН ПЛК\*\*.  

# Система рассчитана на автономную круглосуточную работу (24/7) и устойчива к аварийным отключениям электропитания.

# 

# \---

# 

# \## 🚀 Установка на целевом ПК

# 

# Приложение скомпилировано в автономном режиме (\*\*Self-Contained\*\*) и не требует предварительной установки .NET SDK или сторонних библиотек.

# 

# 1\. \*\*Скачивание и распаковка:\*\*

# &#x20;  \* Перейдите в раздел \[Releases](https://github.com/ntvampire/ksital-telemetry-hub/releases) и скачайте архив последней версии (`ksital-hub-vX.X.X.zip`).

# &#x20;  \* Распакуйте содержимое архива в постоянный рабочий каталог на диске (рекомендуется `C:\\KsitalHub`).

# 

# 2\. \*\*Первоначальная настройка и запуск службы сбора данных:\*\*

# &#x20;  \* Откройте распакованную папку.

# &#x20;  \* Кликните правой кнопкой мыши по файлу \*\*`install.bat`\*\* → \*\*«Запуск от имени администратора»\*\*.

# &#x20;  \* Скрипт автоматически:

# &#x20;    \* Зарегистрирует и запустит системную службу Windows `KsitalTelemetryWorker` со статусом автозапуска (24/7).

# &#x20;    \* Настроит политику автоматического перезапуска службы при возможных сбоях.

# &#x20;    \* Создаст ярлык \*\*«КСИТАЛ Telemetry Hub»\*\* на Рабочем столе.

# 

# 3\. \*\*Первый запуск рабочего места диспетчера:\*\*

# &#x20;  \* Запустите приложение с помощью ярлыка на Рабочем столе (или через `start\_ui.bat` / `UI.Desktop.exe`).

# &#x20;  \* При первом старте система автоматически инициализирует базу данных SQLite в отказоустойчивом режиме \*\*WAL (Write-Ahead Logging)\*\*.

# &#x20;  \* Перейдите в раздел \*\*«⚙ Система»\*\* в главном окне, выберите COM-порт подключенного GSM-модема и нажмите \*\*«Сохранить»\*\*.

# 

# \---

# 

# \## 🔄 Обновление программы

# 

# В диспетчерский интерфейс встроен механизм бесшовного обновления:

# 1\. В главном окне перейдите в \*\*«⚙ Система»\*\* → нажмите \*\*«🔍 Проверить обновления»\*\*.

# 2\. Программа проверит наличие свежего релиза на GitHub.

# 3\. При подтверждении система автоматически скачает пакет, создаст резервную копию базы данных (`telemetry.db.bak`), обновит исполняемые файлы (без затирания рабочей базы) и перезапустится.

#

# \## 🛠 Архитектура решения

# 

# \* \*\*Core\*\*: общие структуры данных, отчеты телеметрии и конструктор команд.

# \* \*\*Modem.Engine\*\*: работа с GSM-модемом по AT-командам и декодирование PDU-пакетов.

# \* \*\*Parser.\*\*\*: изолированные модули разбора SMS для КСИТАЛ, RADS CCU-825 и ОВЕН ПЛК.

# \* \*\*Storage.Sqlite\*\*: хранение объектов, истории показаний, журнала тревог и очереди команд с поддержкой параллельного доступа (WAL-режим, busy timeout).

# \* \*\*Service.Worker\*\*: фоновая системная служба Windows для круглосуточного приема сообщений и отправки исходящих команд.

# \* \*\*UI.Desktop\*\*: графический интерфейс оператора (WPF) с карточками объектов, графиками, всплывающими окнами аварий и контролем очереди команд.
